常见算法思想对比：分治、贪心、动态规划与回溯

发表于2024-03-12|算法与数据结构基础算法
|总字数:1.3k|阅读时长:5分钟|浏览量:

本文解决的问题： 面对新问题时，如何识别分治、贪心、动态规划和回溯等算法思想？

适用范围： 算法入门与解题思路梳理。

结论摘要： 先识别问题的状态、子问题关系和选择约束，再决定使用递归拆分、局部最优、状态转移或搜索枚举。

分治类算法思想

  1. 分治法 (Divide and Conquer)

    核心：将问题分解为子问题→递归解决→合并结果

    Java示例：二分查找

    场景：有序数据查询（时间复杂度： O(log n) ）

  2. 归并排序

    核心：数组分半排序 → 合并有序子数组

    场景：大数据量稳定排序（时间复杂度： O(n log n) ）

  3. 快速排序

    核心：基准分区 → 递归排序子分区

    场景：通用高效排序（平均 O(n log n) ，最坏 O(n²) ）

优化类算法思想

  1. 动态规划 (Dynamic Programming)

    核心：存储子问题解 → 避免重复计算 → 组合最优解

    Java示例：斐波那契数列

    场景：背包问题、最短路径

  2. 贪心算法 (Greedy)

    核心：局部最优 → 期望全局最优

    Java示例：找零钱问题

    场景：霍夫曼编码、Dijkstra算法（不保证全局最优）

搜索与枚举类算法

  1. 回溯法 (Backtracking)

    核心：尝试路径 → 失败则回退 → 枚举所有解

    Java示例：全排列

    场景：N皇后、数独（时间复杂度常为 O(n!) ）

  2. 穷举法 (Brute Force)

    核心：遍历所有可能解 → 验证正确性

    Java示例：线性搜索

    场景：小规模问题（简单但效率低 O(n) ）

  3. 分支限界法 (Branch and Bound)

    核心：回溯法 + 剪枝优化 → 减少无效搜索

    场景：旅行商问题（TSP），需结合优先级队列实现

迭代与递归思想

  1. 迭代法 (Iterative)

    核心：循环逼近解

    Java示例：计算阶乘

    场景：避免递归栈溢出

  2. 递归法 (Recursion)

    核心：函数自调用 → 分解为同类子问题

    Java示例：汉诺塔

    场景：树遍历、分治基础（警惕栈溢出）

其他实用技巧

  1. 双指针 (Two Pointers)

    核心：两指针协同遍历 → 降时间复杂度

    Java示例：有序数组去重

    场景：链表环检测、滑动窗口

  2. 滑动窗口 (Sliding Window)

    核心：动态调整窗口范围 → 高效连续子集处理

    场景：字符串子串匹配、数组连续最值

  3. 位运算 (Bit Manipulation)

    核心：使用位操作加速计算

    Java示例：判断奇偶

    场景：加密算法、高性能计算

算法思想对比表

思想类型 时间复杂度 空间复杂度 特点 典型应用
分治法 O(n log n) O(n) 递归分层处理 归并排序、快速排序
动态规划 O(n²) 或 O(n) O(n) 避免重复子计算 斐波那契、背包问题
贪心算法 O(n log n) O(1) 局部最优但不保全局最优 找零钱、Dijkstra
回溯法 O(n!) O(n) 试错回退 八皇后、全排列
双指针 O(n) O(1) 降低遍历复杂度 数组去重、链表操作
分支限界法 O(b^d) O(bd) 回溯+剪枝 旅行商问题(TSP)
